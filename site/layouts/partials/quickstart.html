Get started

Build the ardur CLI from the workspace, point it at a provider, and take your first turn. The full operator runbook covers the server, channels, and every knob.

{{/* Step 1 — install */}}

Step 1

Build the CLI

cargo install \
  --path crates/cli

Or cargo build --release and run ./target/release/ardur.

{{/* Step 2 — configure */}}

Step 2

Pick a provider

export ARDUR_PROVIDER=anthropic
export ANTHROPIC_API_KEY=sk-ant-…

Or run fully local: ARDUR_PROVIDER=ollama, no key required.

{{/* Step 3 — run */}}

Step 3

Take a turn

ardur chat

Watch the reply stream in as Markdown, and the cost line land token-by-token when the turn closes.
