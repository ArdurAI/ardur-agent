Built for the real world

The three guarantees are what set Ardur apart. These are what make it genuinely usable day to day.

Multi-provider

Claude, OpenAI, Mistral, Llama via Ollama, OpenRouter — bring whatever you pay for. Cost-aware routing picks well.

Multi-channel

Terminal, chat apps, and voice. The same agent, memory, and skills wherever you reach it.

Bi-temporal memory

A record of what was true and when you knew it. Authority and evidence kept separate; forget-and-prove-it on demand.

Skills

Extend the agent with packaged capabilities. Simple SKILL.md format, versioned and shareable.

MCP & ACP

Speaks the open agent protocols, as both a client and a server. Plug into the wider tool ecosystem.

Live model handoff

Switch providers mid-session without losing context. Start on one model, finish on another.

Agent fleet

Run several agents in parallel under one roof, each with its own caps, budget, and receipt chain.

OS-isolated tools

Tool execution is sandboxed at the operating-system level, so a task stays inside the boundary you set for it.
