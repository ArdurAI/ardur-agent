Built for the real world

The three guarantees are what set Ardur apart. These are what make it genuinely usable day to day.

Five providers

Anthropic (Claude), OpenRouter, Ollama (local or cloud), Codex, and Claude‑CLI — bring an API key or a ChatGPT/Anthropic subscription. Chosen at boot.

Four channels

Slack, Matrix, Discord, Telegram — plus the terminal. The same agent, memory, and skills, each with token auth and an allowlist.

Bi-temporal memory

A record of what was true and when you knew it. Event-time and valid-time kept separate; in-process by default, durable on Qdrant.

Hybrid retrieval

Dense recall (fastembed BGE‑small) and sparse recall (Tantivy BM25) fused with reciprocal-rank fusion — meaning and exact terms.

Capability-gated tools

Built-in shell.run, file.*, and http.fetch — each behind a command allowlist, root-confinement, or SSRF defense.

MCP, both ways

Speaks the Model Context Protocol as both client and server, built on rmcp. Plug into the wider tool ecosystem.

Skills

Extend the agent with packaged capabilities. Simple SKILL.md format with progressive disclosure; nine examples ship.

Token streaming

Anthropic, OpenRouter, and Ollama stream token-by-token (SSE / NDJSON) through the full pipeline — no security or audit bypass.
