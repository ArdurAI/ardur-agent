Who is Ardur for?

One agent, many lives. The same security, transparency, and cost model serves very different work.

{{/* Students */}}

Students

Work through homework and research with full citation trails on every claim, a memory of what you've already covered this term, and a hard dollar ceiling so a long night doesn't burn through your API credit.

You'd want this if you've ever lost track of where an answer came from — or how much it cost to get it.

{{/* Researchers */}}

Researchers

Run literature searches, summarize papers, and check reproducibility with claim-to-evidence traceability throughout. The receipt chain means any result can be replayed and shown to a collaborator exactly as it ran.

You'd want this if "where did this number come from?" needs a real answer, not a guess.

{{/* Developers */}}

Developers

A coding assistant that respects filesystem permissions through cap-tokens, signs every commit it makes, and shows you the diff and its reasoning before anything touches your working tree.

You'd want this if you want help in the repo but not a tool with unbounded write access to it.

{{/* Knowledge workers */}}

Knowledge workers

Capture meetings, wire up calendar and email through scoped integrations, and keep spend inside a budget you set. Reach the same agent from your terminal at your desk or a chat app on your phone.

You'd want this if your assistant should follow you across channels without losing the thread.

{{/* Creatives */}}

Creatives

Brainstorm across multiple model personalities, hand off mid-session to a different provider when the work shifts, and keep a provenance trail of where each idea came from — so inspiration stays attributable.

You'd want this if you riff with several models and want to know later which one sparked what.

{{/* Security-conscious power users */}}

Security-conscious power users

Every action is auditable after the fact and every capability is revocable while the agent is mid-flight. Tools run under OS-level isolation, so a single task can't quietly reach beyond what you granted it.

You'd want this if "trust me" isn't an acceptable security model for software running on your machine.
