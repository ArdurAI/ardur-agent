Three things built into the wire format

Security, transparency, and cost awareness aren't features you turn on. They're properties of every single action Ardur takes — because they live in the protocol, not in an afterthought layer.

{{/* Cap-tokens */}}

Cap-token security

Every tool the agent can use is gated by a cryptographically-attenuated capability token. You see exactly what it's allowed to do — and you can revoke or narrow it at any moment.

Like a hotel key card that only opens your floor — and can be re-cut to open even less, mid-stay, without reissuing it.

{{/* Receipt-chain */}}

Receipt-chain transparency

Every action — every tool call, every model request, every file write — is recorded in a tamper-evident, signed receipt chain you can audit, replay, or share.

Like a notarized signature trail — each entry sealed and linked to the last, so the record can't be quietly rewritten.

{{/* Cost-tuples */}}

Cost-tuple awareness

Every action carries its full cost — tokens, dollars, time, attention — attributed at the receipt level. Set per-task, per-day, and per-provider ceilings; the agent respects them.

Like a restaurant pre-bill — you see the running total before you commit, never a surprise at the end.
